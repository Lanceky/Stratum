# Runtime dependencies for the Vercel function.
#
# Deliberately not `verifier/requirements.txt`. That file is the development
# set and carries matplotlib, pytest and the plotting stack, which exist to
# produce the measurement reports offline and are never imported by a request.
# Shipping them costs about 30 MB of bundle for code that cannot run here.
#
# Everything below is reachable from an HTTP request. The heavy three are not
# optional, however much they weigh:
#
#   scipy   — cKDTree, in normalise.py; the constellation match is a
#             nearest-neighbour query and this is what answers it
#   cv2     — findHomography / estimateAffine2D, in checks/presence.py; the
#             geometry signal is a homography residual
#   sklearn — DBSCAN, in masks.py; spot clustering turns a mask into a
#             constellation
#
# Measured bundle: ~338 MB installed, against Vercel's 500 MB Python limit.
# Adding matplotlib back would still fit, but the margin is worth keeping for
# the wheels that grow between now and the next deploy.
